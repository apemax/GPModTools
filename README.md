# GPModTools: G-Police modding tools

GPModTools is a project aimed at creating open source modding tools for the PC version of G-Police and to document the file formats used by the game.

## List of tools:

* `RDTTool`: Extracts asset files from .rdt archive files.
* `IMGtoBMP`: Converts .img files to .bmp files.
* `TEXtoBMP`: Converts .tex, .pal and .bmp texture files to .bmp files.

## Archive and asset file information

All information on the archive file formats and asset file formats can be found on the Wiki [here](https://github.com/apemax/GPModTools/wiki).
